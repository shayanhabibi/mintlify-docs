Xantham turns TypeScript declaration files into F# bindings for your Fable application. Install the .NET tool, point it at an installed npm package, and get generated F# alongside a report that flags every type that widened or needs manual handling.

## How it works

<Steps>
  <Step title="Install the tool">
    `dotnet tool install --global xantham`, then `xantham tsc init` to cache the pinned TypeScript compiler.
  </Step>
  <Step title="Point it at a package">
    Run `xantham generate ./node_modules/your-package -o ./out` from an npm project that has the target package installed.
  </Step>
  <Step title="Add the output to Fable">
    Reference `Xantham.Fable.Core` and `Xantham.Fable.Core.TS`, include the emitted files in your `.fsproj`, and call exports from F#.
  </Step>
  <Step title="Review the report">
    Inspect `manifest.json` and `symbols.jsonl` to find widened or escaped symbols before shipping.
  </Step>
</Steps>

<Note>
  Bindings target **Fable 5.x**. Xantham 0.1.x is an early release. Generated names and shapes may change before 1.0. Pin your Xantham version, keep the reports, and validate the APIs your application actually uses.
</Note>
